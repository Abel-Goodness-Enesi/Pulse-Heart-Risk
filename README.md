# PULSE — static site

Pure HTML/CSS/JS. No server, no build step, no model file.

Files: index.html, style.css, app.js, data.js (model weights + the 848 test patients).

## Deploy on Render
New → Static Site → connect the repo → Build Command: (leave empty) → Publish Directory: `.`

## Deploy on GitHub Pages
Repo → Settings → Pages → Deploy from branch → main / (root).

Not medical advice. Portfolio demonstration only.
